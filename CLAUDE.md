# ASL Translator

An app built on app_builder. The platform rules live in `platform/SPEC.md`: read its "For Claude Code" part before changing anything outside `src/` or `test/`. This file holds only what's specific to this app.

## Decisions already made (do not relitigate without asking)

- **Mode:** solo. Targets are set in `app.config.json`.
- **Logic is pure and deterministic:** no clock, no `Math.random()`, no I/O in `src/app.ts`. Randomness comes from the seed.
- **Everything tunable is config:** rules live in typed config objects with documented defaults. No magic numbers in logic.

## Where things go

| Path | What | Who edits it |
| --- | --- | --- |
| `src/app.ts` | the app's rules: the `GameModule` | you |
| `src/client/` | the UI (`main.ts`, `ui.ts`, `styles.css`) | you |
| `test/` | vitest; every rule gets a test | you |
| `app.config.json` | id, title, mode, targets, host overrides, sprint settings | you |
| `demo/`, `src/client/demo.ts` | the sprint demo: the app as one page that runs with no server | you |
| `snapshots/` | day snapshots from `npm run snapshot`; frozen once their day is over | `npm run snapshot` |
| `platform/`, `wrangler.toml`, `.github/workflows/app.yml`, `scripts/` | generated by app_builder's `sync` | never by hand |

## Rules

- Run `npm run typecheck && npm test && npm run build` before every commit. If the Play target is on, also `npm run build:play` (it fails on any network code).
- Never edit `platform/`. A platform change goes into app_builder, then `sync` brings it here in its own commit.
- No new dependencies without asking.
- The client loads nothing from other origins and uses no inline scripts or styles: the host's CSP is `'self'` only.
- Text from players goes into the page as text (`el(…, { text })`), never as HTML.

## App-specific notes

- **One lexicon, both directions.** `src/asl/lexicon.ts` drives the avatar and is the recognizer's template set. Never add a sign to one side only.
- **The recognizer runs on-device** (MediaPipe hands + pose). No video or landmarks leave the browser.
- **MediaPipe is pinned to 0.10.35**: 1.x posts usage logs to Google with no off switch. Check `grep odml node_modules/@mediapipe/tasks-vision/vision_bundle.mjs` before any upgrade, and keep the URLs in `src/client/vision.ts` in step with the index repo's `site_deps.yml`.
- **`web/asl-translator.html` is committed** (the public page the index publishes). Run `npm run build:web` and commit it with any change to `src/`.
- **Honesty in the UI:** the footer says the signs are unreviewed and recognition is tested on synthetic data. Keep that true; update it when a fluent signer reviews the lexicon or real-camera tests exist.
- `npm test` must stay green: every sign recognized alone, sentences read without pauses.
